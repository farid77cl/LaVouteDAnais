## Como se corre

Las cinco son la **misma pose (Standing)**, el mismo personaje, el mismo escenario y el mismo negative. Entre una y otra cambia **UNA sola cosa**.

1. Genera cada una. 2. Anota solo si **reboto** o si **genero** — no importa si la imagen quedo linda. 3. Mandame los cinco resultados.
