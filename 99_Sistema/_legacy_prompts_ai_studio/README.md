# 🗄️ Legacy — Serie de prompts para AI Studio (#20 a #33)

Archivo histórico de la **serie de prompts que se le escribían a AI Studio** para que él editara el código de LV-App.

**Por qué están aquí — el flujo quedó DEROGADO el 28/08/2026.** La Ama cambió el método: ya no se escribe un prompt y se espera que AI Studio lo ejecute. Ahora se **clona el repo de la app, se edita el código real, se compila con `gradlew assembleDebug` y se entrega el APK**. El prompt dejó de ser el entregable.

Encima de eso, **LV-App 5.0** (rama `v5`, reescritura desde cero, decidida el 28/08) deja obsoleto todo el plan incremental de la 2.0.
